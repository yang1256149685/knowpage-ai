# 架构与边界

## 完整服务

浏览器 ES Modules → 同源 FastAPI → SQLite 文档/文本块/账号/会话/历史 → 可选 chat/completions 兼容模型接口。服务默认只运行一个进程；没有企业 SSO、跨组织多租户、分布式任务或高可用承诺。

TXT/MD 以 UTF-8 读取；文本 PDF 在独立进程解析，父进程 15 秒超时，子进程有 CPU 限制，Linux 下还有 512 MiB 地址空间限制。文件最多 5 MiB、PDF 100 页、提取文本 10 万字符；不保留原始文件到公开路径。

采用每块 600 字符、重叠 100 字符。中文双字词和英文词的可解释词项评分，取至多 3 块并过滤低于最高相关度 45% 的块；不是向量检索。PDF 页标记保留在原文中，引用定位使用文档与文本块编号。生产级语义召回、多轮问题改写和准确页码映射属于后续范围。

无命中不调用模型。检索模式直接摘录原文；live 模式由服务端适配器生成答案，验证 `[n]` 引用属于候选集合。该检查不能证明模型结论都被来源支持，仍需人工核查。适配器已实现，当前尚无真实模型调用证据。

密码使用 PBKDF2-SHA256，随机盐，600000 次迭代。会话随机 token 仅 cookie 持有，数据库只存 hash，8 小时过期；退出立即撤销。history 按 user_id 强制隔离，文档为同一工作空间共享。写请求检查 Origin，cookie SameSite=strict，生产要求 Secure；无 CORS 开放。登录/问答有单进程每 IP 限速，分布式或代理环境需要可信网关和预算控制。

SQLite `user_version=1`；连接启用外键和参数绑定，文档/块事务写入。删除文档同时清除相关历史回答与引用。原始上传内容按文本渲染，不执行 HTML。

## 公开静态体验

相同前端 + config.json 的 local 模式 + localStorage；检索算法由 JS 实现，与 Python 使用相同原创语料。真实导入、检索、引用和历史都在浏览器执行。不存在服务端鉴权，界面明确显示此边界。

## 版本与资源

Python 3.12 本地验证；依赖见 requirements.txt 和 requirements.lock.txt。ES Modules 无运行时外部依赖。没有模型密钥、私有上传、数据库或日志进入源码仓库。
