# 猿急送案例资料：知页 KnowPage

- 项目名称：知页 KnowPage 企业知识库场景演示系统
- 案例性质：个人原创技术作品，AI 辅助开发，非真实企业委托
- 行业：企业效率 / 知识管理 / AI 应用工程
- 实际制作日期：2026-10-20
- 技术：ES Modules、响应式 CSS、FastAPI、SQLite、pypdf、可配置模型接口
- 个人职责：按实际参与情况填写需求、设计、开发、测试和部署；不得把 AI 辅助说成完全手写。

## 可用介绍

知页面向企业资料检索场景，提供文档管理、分块检索、原文引用与问答历史。完整服务支持真实账号会话、管理员/阅读者权限、文本 PDF 解析与用户历史隔离。公开体验使用原创虚构机构资料，真实执行浏览器本地检索，并明确标注未调用大模型。模型适配器已提供，但尚未取得真实 live 调用验证。

## 工程亮点

问题通过词项相关度与当前文档匹配，答案附可核验出处；无依据时明确提示。删除来源会清除相关历史正文。文件解析有大小/页数/文本长度限制，PDF 在受限子进程中处理。数据库与截图均使用虚构示例内容，未借用企业代码或客户数据。

## 图片和链接

docs/screenshots/ 为真实浏览器运行画面；每张标明本地体验或完整本机服务。源码与静态演示以真实发布地址为准。完整后端公网部署未完成前，不写“企业系统已商用上线”。

## 不能宣称

词项检索不是向量数据库；检索摘录不是大模型生成。未实现企业 SSO、多租户、OCR、高并发或 SLA。没有真实客户、合同、用户数量或效率提升百分比；不能保证平台审核通过。
